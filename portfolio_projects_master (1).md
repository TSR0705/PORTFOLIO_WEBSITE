## 1) Android Task Manager App

**Type:** Android / Learning Project  
**Status:** First Android development project  
**GitHub:** https://github.com/TSR0705/Android-TaskManager-App  
**Release / APK:** https://github.com/TSR0705/Android-TaskManager-App/releases/tag/v1.0

### Short Description
A modern offline-first task manager Android app built while learning Android development, demonstrating modern app architecture, declarative UI, and local persistence.

### What It Does

- Store task data offline using Room

- Kotlin

- Room
- Hilt
- Coroutines
- Flow / StateFlow
- Material 3
- MVVM
- Clean Architecture

### Why It Matters
This was my starting point in Android development and helped me understand modern Android architecture, UI composition, state management, and local persistence.

### Tech Stack

- Maven

### Why It Matters

### Portfolio One-Liner
